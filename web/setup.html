Set up this device

To play Everett Kaser's games on this device, it needs to trust the game server's security certificate. You only do this once for each device.

Checking this device…
Download certificate

The server uses a certificate you made yourself (cert.pem), so install the certificate authority that made it on this device instead (for mkcert, that's its rootCA.pem).

Android

  1. Tap Download certificate. If Chrome says the file can't be downloaded securely, choose Keep or Download anyway.
  2. Open Settings and search for CA certificate. It's usually under Security (or Security & privacy) → More security settings → Encryption & credentials → Install a certificate → CA certificate.
  3. Tap Install anyway, unlock the device if asked, and pick kaser-games-certificate.crt from Downloads. (Android only allows this when the device has a screen lock such as a PIN.)
  4. Come back here and tap Check again. If it still says “not yet”, close Chrome completely and open this page again.

iPhone or iPad

  1. Open this page in Safari (other browsers on iPhone and iPad can't install certificates), tap Download certificate and then Allow.
  2. Open Settings, tap Profile Downloaded near the top, then Install, and enter your passcode.
  3. In Settings, go to General → About → Certificate Trust Settings and turn on Kaser games on ….
  4. Come back here and tap Check again. After that, Chrome works too.

Another computer

  1. Download the certificate and open the file.
  2. Windows: Install Certificate → Current User → “Place all certificates in the following store” → Browse → Trusted Root Certification Authorities → Finish, and answer Yes.
    Mac: it opens in Keychain Access. Double-click “Kaser games on …”, open Trust, and set “When using this certificate” to Always Trust.
  3. Quit Chrome completely, open it again, and come back to this page.
Other kinds of device

The certificate only lets this device recognise the game server. Its secret key never leaves the computer running the server. You can remove it later where you installed it.
